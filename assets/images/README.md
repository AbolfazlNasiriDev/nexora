# تصاویر NEXORA

تصاویر محصولات، بنرها و آواتارها در این پروژه به‌صورت SVG برداری و محلی توسط `js/images.js` ساخته می‌شوند و به شکل Data URI در صفحات قرار می‌گیرند.

دلیل این انتخاب:

- هیچ تصویر شکسته یا وابسته به اینترنت وجود ندارد.
- حجم صفحه سبک می‌ماند و تصاویر در هر اندازه‌ای شارپ هستند.
- رنگ و فرم تصاویر با هویت بصری برند (`#5B45E8` / `#15172B`) هماهنگ است.

برای جایگزینی با عکس‌های واقعی، فایل‌ها را با نام دلخواه در همین پوشه قرار دهید و آدرس آن‌ها را در `js/products.js` (فیلد `art` یا `image`) استفاده کنید.
